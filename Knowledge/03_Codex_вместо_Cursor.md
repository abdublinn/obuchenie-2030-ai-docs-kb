# Codex вместо Cursor

Домашнее задание выполнено в Codex. Концепции урока сохранены, но реализованы
средствами текущего инструмента.

| В уроке Cursor | В этом проекте Codex |
|---|---|
| Папка проекта | Отдельная папка четвёртого ДЗ |
| Правила Cursor | `AGENTS.md` |
| История проекта | `ДНЕВНИК.md` |
| Индекс базы | `index.md` |
| Повторяемые промты | Markdown в `Instructions` |
| Контроль правок | Проверка файлов и `git diff` |
| Коммиты | Локальный Git |
| Режим без изменений | Явная read-only задача для Codex |

## Почему не создавался глобальный навык

Процесс пока проверяется на одном учебном проекте. Проектные инструкции
достаточны и не влияют на остальные задачи Codex. Решение о глобальном навыке
можно принимать только после нескольких реальных применений и отдельного
разрешения владельца.

## Безопасная граница

Codex может подготовить файлы, проверить структуру и сделать локальный коммит.
Публикация в GitHub, отправка тьютору и любые другие внешние действия требуют
явного подтверждения.
