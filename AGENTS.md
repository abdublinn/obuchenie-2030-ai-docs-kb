# Правила работы Codex с базой знаний

## Назначение проекта

Это учебная и одновременно рабочая база знаний по применению ИИ. Она должна
оставаться понятной человеку, переносимой между ИИ-инструментами и безопасной
для последующего размещения в приватном репозитории.

## Обязательный порядок работы

1. Перед изменениями прочитать `ДНЕВНИК.md`, затем `index.md`.
2. Входящие материалы брать только из `Inbox`.
3. Не удалять и не перемещать исходник до проверки созданного результата.
4. Отделять факты источника от выводов и рекомендаций ИИ.
5. Не выдумывать отсутствующие сведения; неопределённость помечать явно.
6. После добавления или переименования знания обновлять `index.md`.
7. Готовые к передаче материалы сохранять в `Output`.
8. Внешнюю публикацию, отправку и создание удалённого репозитория выполнять
   только после явного разрешения пользователя.

## Форматы

- Рабочие знания, инструкции и конспекты: Markdown UTF-8.
- Исходные Word, Excel, PDF, аудио и видео: хранить отдельно от производных
  Markdown-файлов и не считать автоматически проверенными.
- Если итог нужен в DOCX или PDF, сначала проверить смысл, затем оформление.

## Конфиденциальность

- Не добавлять в репозиторий секреты, токены, пароли и файлы `.env`.
- Не публиковать персональные данные, клиентские документы и записи встреч без
  отдельного решения о допустимости.
- При сомнении остановить публикацию и запросить решение пользователя.

## Git

- Один завершённый смысловой этап — один понятный коммит.
- Перед коммитом проверить `git diff` и отсутствие чувствительных данных.
- Большие бинарные файлы и медиа в Git не добавлять.
- `main` должен содержать только проверенное состояние.
