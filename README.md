# База знаний по обучению 2030 AI

Практическое задание к уроку «Cursor для работы с документами (без кода)»,
выполненное в **Codex**, а не в Cursor.

Приватный репозиторий: <https://github.com/abdublinn/obuchenie-2030-ai-docs-kb>

Проект показывает рабочий цикл обращения с документами:

1. Новый материал попадает в `Inbox`.
2. Codex разбирает его по инструкции из `Instructions`.
3. Проверенное знание сохраняется в `Knowledge`.
4. `index.md` обновляется и остаётся точкой навигации.
5. Готовый результат складывается в `Output`.
6. Изменения фиксируются в локальном Git после проверки человеком.

## Структура

```text
Inbox/          необработанные входящие материалы
Instructions/   повторяемые рабочие инструкции для Codex
Knowledge/      проверенная база знаний
Sources/        сведения об исходных уроках и источниках
Output/         материалы, готовые к передаче
AGENTS.md       правила работы ИИ в проекте
ДНЕВНИК.md      текущее состояние и передача контекста
index.md        карта базы знаний
```

## Быстрый старт

1. Открыть `index.md`.
2. Положить новый файл в `Inbox`.
3. Попросить Codex выполнить `Instructions/01_Разобрать_входящий_документ.md`.
4. Проверить предложенную классификацию и итоговый Markdown.
5. После подтверждения переместить материал в `Knowledge` и обновить индекс.

## Важные ограничения

- Помещение файла в `Inbox` само по себе ничего не запускает.
- Исходник не удаляется до проверки результата.
- Конфиденциальные документы и персональные данные не публикуются в GitHub.
- Markdown используется как рабочий формат знаний, но не заменяет итоговые
  Word, Excel или PDF, когда важно оформление.
- Внешняя отправка и публикация выполняются только по отдельному разрешению.
