# Инструкция: обновить индекс базы знаний

1. Получить список Markdown-файлов проекта.
2. Сопоставить его с существующими ссылками в `index.md`.
3. Добавить отсутствующие содержательные файлы в подходящий раздел.
4. Удалить или исправить только доказанно битые ссылки.
5. Для каждой ссылки дать одно короткое описание назначения файла.
6. Обновить дату в начале индекса.
7. Проверить, что все относительные ссылки открываются.

Индекс не должен превращаться в автоматический список всех технических файлов:
он содержит только полезные человеку точки входа.
