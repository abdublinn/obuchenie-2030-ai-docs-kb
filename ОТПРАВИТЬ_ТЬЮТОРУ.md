# Какой файл отправить тьютору

После подключения GitHub отправить:

`Output/ОПИСАНИЕ_ПРОЕКТА_ДЛЯ_ТЬЮТОРА.md`

Предлагаемый текст сообщения:

> Выполнил домашнее задание в Codex, а не в Cursor. Создал структурированную
> базу знаний с Inbox, индексом, AGENTS.md, повторяемыми инструкциями и Git.
> Прикладываю описание проекта. Ссылка на репозиторий: [добавить после
> разрешённого подключения GitHub].

Пока GitHub не подключён, сообщение тьютору не отправлять: второй пункт задания
ещё не подтверждён внешним репозиторием.
