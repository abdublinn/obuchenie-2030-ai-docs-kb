# Inbox

Сюда помещаются новые документы и записи, которые ещё не разобраны.

Правила:

1. Один входящий материал обрабатывается за один цикл.
2. Исходник сохраняется до проверки результата.
3. Разбор выполняется по
   `../Instructions/01_Разобрать_входящий_документ.md`.
4. Добавление файла в эту папку не запускает обработку автоматически.
5. Входящие материалы исключены из Git, кроме этого README.
